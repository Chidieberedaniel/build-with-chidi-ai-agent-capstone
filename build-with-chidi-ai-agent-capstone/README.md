# BUILD WITH CHIDI — AI Agent Content Planning Capstone

## Project overview

This capstone documents a three-run AI-agent workflow used to develop a one-week social media content pilot for BUILD WITH CHIDI, a Nigeria-based, AI-focused technology brand.

The project demonstrates how an AI agent can be directed through a structured task, reviewed against acceptance criteria, corrected through feedback, and evaluated before a production handoff.

## Project objectives

- Translate brand positioning, audience needs and content pillars into clear agent instructions.
- Direct the agent through three iterative runs.
- Review outputs, identify weaknesses and provide corrective feedback.
- Produce a structured content plan containing three core content pieces across Instagram, LinkedIn and TikTok.
- Preserve run evidence, change records and independent evaluations.

## What the project contains

- **Project context:** audience positioning, brand guidelines and content strategy.
- **Agent instructions:** initial prompt, acceptance criteria, and source/file rules.
- **Agent runs:** prompts, work logs, change records, reviews and workbook outputs for Runs 01–03.
- **Independent evaluation:** evidence-based evaluations of each run and a final assessment.

## Final outcome

Run 03 was accepted for **production handoff**. It was **not approved for immediate publication**. The final workbook is a planning deliverable; publication depends on creating the required visual assets, completing and documenting the planned P03 prompt experiment before making result-led claims, using owner-approved logo artwork, and obtaining owner approval of the final content and schedule.

No experiment results, performance metrics, testimonials, client outcomes or deployed automation claims are fabricated or implied.
